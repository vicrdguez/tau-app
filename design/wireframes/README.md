# Wireframes

Greyscale renders of four states with every frame region outlined and labelled with its box (x, y, w, h in px): `wire-home.png`, `wire-conversation-streaming.png`, `wire-decision-long.png`, `wire-readback-answer.png`. They show `../spec.md` §4's calm frame (sidebar, stage header, stage, peek, bottom float, bottom bar) on real content; in `wire-readback-answer.png` the stage's box ends at the float's top edge, where the page is clipped.
